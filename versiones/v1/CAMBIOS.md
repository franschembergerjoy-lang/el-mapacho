# Versión 1 — primera versión jugable

Fecha: 2026-10-18 · etiqueta git `v1`

- Proyecto Unity 6000.6.6f1 (URP) con menú principal, selección de niveles y 5 niveles.
- Mapache con cola rayada, máscara y animaciones por código (caminar, correr, agacharse, recoger, esconderse, ser atrapado).
- Habitantes que duermen, patrullan, investigan ruidos, persiguen y buscan; perro; cámaras de seguridad; sensores de movimiento.
- Botín de 11 tipos con valor, espacio y ruido; mochila de 10; varios viajes a la salida.
- Barra de ruido (30/60/100), escondites, pantallas de victoria/derrota con estrellas, pausa con volumen.
- Controles: WASD/flechas, Shift correr, Ctrl/C agacharse, E robar/esconderse/escapar, Q soltar, Esc pausa.

Ejecutable (solo en la PC, no en GitHub): `versiones/v1/Build/RobaYCorre.exe`.
Para abrir el código fuente de esta versión en Unity, copia esta carpeta a otro lugar y ábrela con Unity Hub.
